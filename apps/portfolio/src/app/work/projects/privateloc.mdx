## Overview

Privateloc is a mobile application designed for a car and house rental agency, streamlining the property rental process for both customers and agency staff.

## Key Features

- **Property Listings**: Comprehensive car and house listings with detailed information
- **Booking Requests**: Easy booking system for customers
- **Client Management**: Efficient customer relationship management
- **Push Notifications**: Real-time updates on booking status
- **Secure Payments**: Stripe payment integration for safe transactions
- **Geolocation**: Google APIs for property location and navigation

## Technologies Used

- **Flutter**: Cross-platform mobile framework
- **Stripe**: Payment processing
- **Google APIs**: Maps and geolocation services
- **Firebase**: Backend services and authentication
- **REST APIs**: Server communication

## Technical Implementation

The application uses Google Maps API to display property locations and provide navigation assistance. Stripe integration ensures secure payment processing for rental transactions.

Firebase services handle user authentication and push notifications, keeping users informed about their booking status in real-time.

## Platform Support

Available on both Android and iOS, providing a wide reach for the rental agency's customer base.
