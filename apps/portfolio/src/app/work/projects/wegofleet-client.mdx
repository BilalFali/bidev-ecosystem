## Overview

Wegofleet Client App is a comprehensive cross-platform ride-booking application designed for passengers. The app provides a seamless experience for requesting rides, tracking drivers in real-time, and managing bookings.

## Key Features

- **Real-time Ride Requests**: Instant ride booking with live driver matching
- **Fare Estimation**: Accurate fare calculation before booking
- **Driver Tracking**: Real-time driver location tracking on Google Maps
- **Booking History**: Complete history of all rides
- **In-app Notifications**: Push notifications for ride updates
- **Secure Payments**: Stripe Payment Gateway integration
- **User Authentication**: Firebase Authentication for secure login

## Technologies Used

- **Flutter**: Cross-platform mobile development
- **Firebase**: Authentication, Firestore, Cloud Messaging
- **Stripe**: Payment processing
- **Socket.IO**: Real-time communication
- **GetX**: State management
- **Google APIs**: Maps and location services
- **REST APIs**: Backend integration
- **MVC+S Architecture**: Clean code structure

## Technical Highlights

The application implements a robust architecture using MVC+S pattern, ensuring maintainability and scalability. Firebase services provide real-time updates for ride status, while Socket.IO enables instant communication between passengers and drivers.

Google Maps integration offers precise location tracking and route visualization. The payment system is secured through Stripe, handling transactions safely and efficiently.
